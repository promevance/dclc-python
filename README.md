# Python Assignments

This repository contains my Python exercises for learning and practicing programming, data analysis, and problem-solving.

---

## 🗂 Repository Structure

| File | Description |
|------|-------------|
| `basic-python.py` | Contains the first set of 5 simple Python exercises.
| `data-structures.py` | Contains the second set of 10 Python exercises focused on basic data structures. I improved script execution such individual exercises can be run independently without executing the entire script.
| `date-and-time.py` | Contains date and time python exercises.
| `dict-and-tuple.py` | Contains assignment exercises involving tuples, lists, and dictionaries.
| `oop.py` | Contains assignment exercises designed to help get acquianted with object-oriented programming. I learnt about classes, inheritance, polymorphism amongs others
| `UK-covidproject` | Contains project assignment done with UK COVID-19 data to show experience with pandas dataframes and matplotlib
